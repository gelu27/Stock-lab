# 台股觀測實驗室 v2：上線步驟（手機也能做）

## 這一版有什麼
- **01 市場總覽**：加權指數、漲跌家數、成交金額、漲幅／跌幅／成交值排行
- **02 選股**：左側勾選條件（本益比、殖利率、淨值比、均線、RSI、量比、20 日漲幅、成交量、股價），附個股 K 線圖
- **03 回測**：用同一組條件模擬過去買賣，算出總報酬、年化報酬、最大回撤、勝率，並和 0050 比較
- **自建資料庫**：GitHub 每個交易日晚上 6 點自動下載交易所資料，保留近 3 年

## 檔案清單（6 個）
| 檔案 | 用途 |
|---|---|
| `app.py` | 網站共用部分（頁首、選單、共用函式、頁尾） |
| `views/p01_market.py`…`p09_stats.py` | 各頁畫面，一頁一個檔案，只執行目前這一頁 |
| `engine.py` | 選股與回測的計算規則 |
| `update_data.py` | 下載交易所資料、建立資料庫 |
| `requirements.txt` | 需要安裝的套件 |
| `.streamlit/config.toml` | 黑底主題 |
| `.github/workflows/update.yml` | 每天自動更新資料庫的排程 |

## 上線步驟
1. **建立 GitHub 專案**：登入 github.com →「+」→「New repository」，名稱例如 `stock-lab`，選 Public，按 Create。
2. **放入 6 個檔案**：（如果選擇讓 Claude 幫你上傳，這步可跳過）
   「Add file」→「Create new file」，檔名欄位照上表輸入（含資料夾，例如 `.github/workflows/update.yml`），貼上內容後按「Commit changes」。
3. **建立資料庫**：專案上方「Actions」→ 左側「更新資料庫」→「Run workflow」。
   第一次要下載 3 年資料，大約 1 到 2 小時，跑完會看到綠色勾勾。之後每個交易日自動更新。
4. **發布網站**：到 share.streamlit.io 用 GitHub 登入 →「Create app」→ 選 `stock-lab`，Main file 填 `app.py` →「Deploy」。

## 回測規則說明
- 每月（或每週）最後一個交易日收盤後選股，**隔天收盤價**買進，避免「用今天的資料、今天就買」的作弊。
- 每檔投入「總資產 ÷ 最多持有檔數」，沒入選的持股賣出。
- 停損／停利以收盤價判斷，觸發當天收盤賣出，資金等下次調倉再投入。
- 已扣手續費 0.1425%（買賣各一次）與證交稅 0.3%。
- 使用還原股價，除權息不會被誤判成大跌。

## 限制
- 目前只有上市股票（不含上櫃），上櫃之後可以加。
- 本益比、殖利率是交易所每日公布的數字；營收、EPS、法人籌碼屬於下一階段。
- 回測結果是歷史模擬，不代表未來報酬；僅供個人研究，不構成投資建議。
